# Records

Records preserve dated investigations, review rounds, decision dossiers, and
characterization evidence. They are not automatically published; the public
subset is listed explicitly in [`../index.yml`](../index.yml).

Direct records:

- [Racc migration evidence](racc-migration-evidence.md)
- [Repair semantics](repair-semantics.md)
- [Test interactions](test-interactions.md)

Record groups:

- [`conflict-explanation/`](conflict-explanation/README.md)
- [`error-ux/`](error-ux/README.md)
- [`ielr/`](ielr/README.md)
- [`investigations/`](investigations/README.md)
- [`profiles/`](profiles/README.md)

The inclusion test is an immutable record identity and date. Corrections are
new records or explicit supersessions, not silent edits to historical claims.
