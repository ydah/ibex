# Support

Use the project site for the normal path:

- [Getting Started](https://ydah.github.io/ibex/getting-started/) for installation and the first parser.
- [Documentation](https://ydah.github.io/ibex/docs/) for grammar, runtime, migration, and configuration questions.
- [Playground](https://ydah.github.io/ibex/playground/) for bounded browser experiments.
- [GitHub Issues](https://github.com/ydah/ibex/issues) for reproducible bugs and feature requests.

When filing a bug, include the Ibex version, Ruby version, operating system,
grammar or a reduced reproduction, command line, and complete diagnostic
output. Remove secrets and proprietary grammar source. For security reports,
follow [`SECURITY.md`](SECURITY.md) instead of opening a public issue.
