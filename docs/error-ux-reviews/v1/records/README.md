# Independent error UX review records v1

Published third-party JSON records belong in this directory and are registered,
by path and SHA-256, in
[`error-ux-review-status-v1.json`](../../../error-ux-review-status-v1.json).
The directory intentionally contains no JSON while R001 is on HOLD.

Import a reviewer's published JSON byte-for-byte. Do not normalize wording,
labels, rationales, or disagreement notes. The repository quality task rejects
unregistered files, drafts, maintainer self-reviews, mutable publication links,
missing consent, placeholders, identity drift, and incomplete case sets.

See the [v1 rubric](../../../error-ux-review-rubric-v1.md) for the independent
review and publication workflow.
