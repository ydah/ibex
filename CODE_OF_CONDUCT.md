# Code of Conduct

Ibex aims to be a welcoming, technically rigorous project. Participants must
be respectful, assume good faith, and focus criticism on ideas and evidence.
Harassment, discrimination, threats, doxxing, sexualised conduct, and
deliberate disruption are not acceptable.

Maintainers may remove comments, close discussions, or restrict participation
when necessary to keep the project safe and productive. For concerns about
conduct, contact the maintainers through the private channel described in
[`SUPPORT.md`](SUPPORT.md). Do not report a security vulnerability in a public
issue.
